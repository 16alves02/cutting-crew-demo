# CUTTING CREW: protótipo de website

Versão demo de uma página só (React + TypeScript + Vite), para apresentação à barbearia. Protótipo privado e não oficial: não publicar nem indexar sem autorização.

Secções: início, serviços, galeria, equipa, marcação, perguntas e localização.

Dados provisórios (Fresha e Linktree) em `src/data/`. A confirmar com o proprietário. A galeria e a equipa têm espaços reservados até haver fotografias autorizadas.

## Executar
Node 20.19 ou superior.
- `npm install`
- `npm run dev` (http://localhost:5173)
- `npm run build` (gera `dist/`)

Demo online: [Abrir a demo](https://cutting-crew-demo-16alves02.vercel.app). O `vercel.json` já está configurado para publicação.
